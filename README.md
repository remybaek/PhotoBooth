# 📸 2026 Life 4-Cuts Web App (인생 4컷 웹앱)

2026년 UI 디자인 트렌드를 반영한 감각적인 웹 기반 인생 4컷 사진 촬영 애플리케이션입니다. 

## ✨ 주요 기능
- **웹캠 촬영:** 브라우저에서 바로 카메라를 연결하여 사진을 촬영합니다.
- **실시간 필터:** 흑백, 세피아, 레트로 등 다양한 감성 필터를 실시간으로 적용해 보세요.
- **자동 프레임 정렬:** 4번의 촬영이 끝나면 트렌디한 프레임에 사진이 예쁘게 자동 정렬됩니다.
- **원클릭 다운로드:** 완성된 인생 4컷을 즉시 이미지 파일(PNG)로 기기에 저장할 수 있습니다.

## 🎨 디자인 특징
- **Glassmorphism (글래스모피즘):** 투명도와 블러 효과를 활용한 세련된 UI.
- **Aurora Background:** 시선을 사로잡는 미래지향적인 그라데이션 배경.
- **Responsive Design:** 모바일, 태블릿, 데스크탑 어디서든 완벽하게 작동합니다.

## 🚀 사용 방법
1. 웹 페이지에 접속하면 카메라 권한을 허용해 주세요.
2. 하단의 필터 선택 드롭다운에서 원하는 분위기의 필터를 고릅니다.
3. **"📸 촬영 시작"** 버튼을 누르면 3초 간격으로 4장의 사진이 연속 촬영됩니다.
4. 화면 중앙에 카운트다운이 표시되니 멋진 포즈를 취해 보세요!
5. 촬영이 완료되면 우측(또는 하단)에 완성된 4컷 사진이 나타납니다.
6. **"저장하기"** 버튼을 눌러 사진을 간직하세요.

## 🛠 기술 스택
- HTML5, CSS3 (Tailwind CSS)
- Vanilla JavaScript (WebRTC API, Canvas API)
